# EVA 段落导图

1. 读取用户指定的段落，按原顺序编号 S1、S2……，每个原文句子对应一张卡，独立问句也单独成卡。
2. 每张卡使用简短英文关键词或短语。句内各要点逐行排列，每项前加小黑点。保留有助于理解的限定语，把句内细节并入对应要点。
3. 根据原文画树，箭头只连接句子卡。卡片放在箭头末端，英文关系标签紧邻箭头。按含义确定连接对象，避免只凭连接词判断。
4. 优先选用 Example（举例）、Contrast（对比）、Analogy（类比）、Shift（转折）、Opinion（个人观点）、Reason（原因）、Result（结果）、Description（特征描述）、Process（流程）、Narrative（讲故事）、Parallel（并列）、Problem–Solution（问题－解决方案）。独立提问可用 Question，回答原因的句子可用 Reason 接在问句下。将观点句连到它评论的信息。保留希望、推测或计划的语气。
5. 默认输出纸艺风格的树状图：暖木纹背景、米白撕边纸、浅色内容卡、深蓝英文和红色关系标签。优先使用可用的图像工具。交付前检查句子编号和原文一一对应、每个要点都有行首黑点、标签与箭头匹配、每个箭头尖端清楚指向对应卡片。图像工具不可用时，仍用可用的绘图方式呈现同一结构。
